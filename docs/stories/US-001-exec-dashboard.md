## 用户故事

> **作为**一名负责 Agent 产品投入决策的高管，
> **我想要**打开一个页面就看到「这个 Agent 产品值不值得继续、问题主要在技术还是产品/运营、质量和业务表现如何、花了多少钱换来多少效果」，
> **以便于**我不用看技术细节就能做出继续/放弃/再等等的判断，且知道这个结论有多可信、依据是什么。

## 验收标准（Given / When / Then）

### AC-1 一眼看到三态结论
- **假设** 系统已算出一份归因决策（继续/放弃/再等等）
- **当** 我打开对上 Dashboard
- **那么** 我看到醒目的门禁徽标（GO 绿 / NO-GO 红 / ABSTAIN 黄）和一句话推荐
- **并且** 我不需要理解任何技术术语就能明白结论

### AC-2 看到问题归因到谁
- **假设** 决策附带技术/产品/运营三方归因
- **当** 我查看归因区
- **那么** 我看到三方各占多少 + 每一方的置信度（高/中/低）

### AC-3 看到质量、业务、财务三本账
- **假设** 有质量/产品/财务指标
- **当** 我查看 KPI 区
- **那么** 我看到：
  - **质量**：任务成功率、可靠性(pass^k)、回归数
  - **业务**：采用率、留存、满意度、任务量、自足完成率
  - **财务**：每成功任务成本(Cost-of-Pass)、ROI、成本-质量
- **并且** 不是一个孤立的准确率数字

### AC-4 护栏破线一眼看到
- **假设** 幻觉率/拒答率/安全违规/延迟等护栏指标有的破了线
- **当** 我查看护栏区
- **那么** 破线的指标标红告警（不能变差的东西变差了，我要立刻知道）

### AC-5 知道结论可不可信、能不能深究
- **假设** 数据源（连接器）只能提供指标、无案例血缘（metric-only）
- **当** 我查看任一数字
- **那么** 系统明确告诉我"低证据级、不可下钻、不可作为拍板唯一依据"，下钻按钮禁用

### AC-6 能看到决策依据和反对意见
- **当** 我展开"决策依据"
- **那么** 我看到推荐理由、敏感性分析、**反对这个结论的证据**
- **并且** 我据此自己拍板（系统只支持决策，不替我拍板 —— D8.2）

### AC-7 数据来源可换，我无感
- **假设** 今天数据来自 mock，明天换成真实评测/BI
- **当** 后台把连接器从 MockConnector 换成真实连接器（同一标准接口）
- **那么** 我看到的页面结构不变、只是数字变真（视图经连接器拉取，D9.2）

## 不在本故事内
- 点开下钻看到真实证据链（需 L2，后续故事）
- 产品/工程师视角（后续故事）
- 真实评测数据 / 真实 BI 连接器（本故事用 MockConnector）
- UI 可视化配置数据源（本故事用前端配置文件）

## 演示脚本
1. `pnpm --filter @kaogongsi/web dev` 打开 Dashboard，看到 GO 徽标 + 归因 + 四组 KPI（护栏破线标红）+ 决策依据
2. 切到 metric-only 连接器 fixture，看到"不可下钻"、按钮禁用
3. 用"假 L5 连接器"替换 MockConnector，页面结构不变、数据变化（验证可替换）
4. `pnpm e2e` 四场景全绿
