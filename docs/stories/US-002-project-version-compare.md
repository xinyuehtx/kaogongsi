## 用户故事

> **作为**负责某 Agent 产品迭代决策的产品/高管，
> **我想要**按「项目 → 版本」查看评测报告，并能**把本轮版本与某个基线版本对比**、一键**生成一份可读的对比报告**，
> **以便于**我快速判断这一版相对上一版是变好还是变差、值不值得放量，并知道结论的依据与风险（护栏有没有破线）。

## 验收标准（Given / When / Then）

### AC-1 按项目/版本浏览
- **假设** 前序流程已为多个项目的多个版本产出评测数据
- **当** 我在顶栏选择项目、选择版本
- **那么** 我看到该项目该版本的单版本报告（门禁 + 归因 + 四组 KPI + 决策依据）

### AC-2 选择单版本或两版本对比
- **当** 我切到「双版本对比」并选择基线与候选版本
- **那么** 我看到逐指标的对比（基线值 → 候选值 + 变化量 + 方向）
- **并且** 显著的变化被标注（非噪声），诊断类指标标「诊断非打分」不参与门禁

### AC-3 护栏回退一眼可见
- **假设** 候选版本某护栏指标破线（如幻觉率超阈值）
- **当** 我查看对比
- **那么** 该指标标红并单列，门禁迁移显示为 → NO-GO

### AC-4 一键生成对比报告（LLM）
- **当** 我点击「生成对比报告」
- **那么** 我得到一段可读报告：总结 + 改善点 + 回退/风险 + 决策建议 + 建议门禁
- **并且** 报告明确「决策支持、人工拍板」，不替我拍板（D8.2）

### AC-5 数据源与模型都可换，我无感
- **假设** 今天数据来自 mock、报告用离线模板；明天换真实评测源、真实 LLM
- **当** 后台换连接器 / 配置 LLM env
- **那么** 我看到的页面结构不变，只是数据变真、报告由真实模型生成

### AC-6 低证据级不伪装
- **假设** 某数据源只有指标、无案例血缘（metric-only）
- **那么** 报告标「低证据级、不可下钻」，下钻按钮禁用

## 不在本故事内
- 三个以上版本多路对比 / 版本趋势时间线
- 真实下钻到证据链（需 L2）
- 前端直连真实 LLM（key 只在服务端）

## 演示脚本
1. `pnpm --filter @tengxiaohtx/web dev` → 选「钉钉 AI 表格 Agent」，看 v2.0 单版本报告（GO）。
2. 切「双版本对比」，基线 v1.0 / 候选 v2.0 → 看逐指标改善 + 显著性；点「生成对比报告」→ verdict GO。
3. 选「飞书文档助手 Agent」（v0.9→v1.0）→ 幻觉率破线标红、门禁 → NO-GO；生成报告 verdict NO-GO、建议暂停放量。
4. `pnpm e2e` 全绿。
